# Nihongo Telegram Bot (Revisi Fitur)

### Fitur Baru yang Diterapkan:
1. **Interactive Keyboard Menu**: Pilihan tombol langsung di layar Telegram tanpa perlu ketik manual.
2. **Drill Partikel (Rumpang)**: Soal memilih partikel dengan opsi tombol pilihan dan penjelasan fungsi partikel. Otomatis lanjut ke soal berikutnya setelah dijawab.
3. **Drill Terjemah (ID -> JP)**: Bot memberikan kalimat Bahasa Indonesia, Anda menuliskan Bahasa Jepangnya (Romaji/Kana/Kanji). Gemini mengevaluasi tata bahasa, lalu langsung otomatis memberikan kalimat latihan berikutnya.
4. **Kaiwa Santai (Romaji + Arti)**: Bot Senpai merespons hanya dalam format Romaji dan terjemahan Bahasa Indonesia, menanyakan kabar/kegiatan, serta mengingat memori percakapan sebelumnya.
5. **Auto Push Bacaan Kana**: Teks kana dikirim otomatis jam 12.00 dan 20.00 WIB sebagai reminder harian.
6. **Perintah `/end` & Auto Next**: Keluar ke menu utama kapan saja dengan tombol atau ketik `/end`.
